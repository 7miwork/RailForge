# Railforge
Automatisierungsspiel mit Transport-Tycoon- und RPG-Elementen
(Factorio + Satisfactory + Dyson Sphere Program).
Die Grafik entwickelt sich im Spielverlauf von Game-Boy-Monochrom bis modernem 3D (Evoland-Prinzip).

Entwickelt mit Godot 4. Läuft zuerst auf Windows, macOS und Linux, später Android und iOS.

## Status
Phase 0 (Fundament, nur Struktur) – siehe [docs/PHASEN_GUIDE.md](docs/PHASEN_GUIDE.md).
Phase 1 ist in Etappen 1.1–1.6 gegliedert.

## Starten
Godot 4.3+ öffnen → Importieren → `project.godot` → F5.

## Git-Konvention
Arbeit auf `main`. Ein Commit pro Etappe. Ein Tag pro Phase (`phase-0-fundament`, `phase-1-monochrom`, …).
Rollback per `git checkout <tag>`.
